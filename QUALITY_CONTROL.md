# QUALITY_CONTROL.md

**Acceptance Checklist for Any Generated AVA Image or Video**

Status: AUTHORITATIVE

Before accepting any generated asset, verify all of the following.

---

## CHARACTER

- [ ] Does she look like canonical AVA?
- [ ] Same face structure?
- [ ] Same freckles present and correctly placed?
- [ ] Same hair (black with purple accents)?
- [ ] Same apparent age (mid-to-late 20s)?
- [ ] Same body proportions?
- [ ] Eye color correct (warm brown)?

If any answer is “no” → reject.

---

## CONTINUITY (for sequential clips)

- [ ] Same environment / architecture?
- [ ] Same clothing / wardrobe?
- [ ] Same lighting direction and quality?
- [ ] Same background people and props?
- [ ] Same camera geography (or motivated continuous move)?
- [ ] Emotional and story state continues correctly?

---

## PERFORMANCE

- [ ] Natural movement and body mechanics?
- [ ] Natural facial expressions matching intent?
- [ ] Natural dialogue delivery and lip synchronization?
- [ ] No robotic or uncanny motion?

---

## STORY

- [ ] Action follows the written script / beat sheet?
- [ ] Continues from the previous clip’s ending state (if applicable)?
- [ ] Dialogue is accurate?

---

## BRAND

- [ ] Feels like OPERAVA?
- [ ] Preserves AVA’s role as emergency operational backup?
- [ ] Does not turn AVA into a literal superhero with powers?
- [ ] Tone remains professional with dry comedy where intended?

---

## Final Decision

All critical boxes must pass.  
Any failure on character identity or major continuity is an automatic reject.
