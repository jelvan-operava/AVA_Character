## Usage Notes

- Always include the PREVIOUS CLIP STATE and ENDING STATE sections for multi-clip work.
- Keep dialogue exactly as written in the campaign documents unless a deliberate revision is approved.
- When generating, attach or strongly reference the canonical AVA images.
