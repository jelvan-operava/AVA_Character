# References

## Canonical AVA Images

All original reference images that defined AVA’s visual identity are currently stored at the repository root (the original `.webp` files).

These images are **AUTHORITATIVE**.

### Intended Organization (to be completed when binary moves are practical)

```
references/
  canonical/
    portraits/     ← close-ups / headshots
    full-body/     ← full figure, multiple angles
    expressions/   ← key performance states
    environment/   ← AVA in key environments (when available)
```

Until the files are physically moved into subfolders, treat every original `.webp` reference image at the root as belonging to `references/canonical/`.

**Do not overwrite or delete them.**

Generated outputs must never be placed here.
